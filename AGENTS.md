## Project reference

- `ryodan-keys/` is the Foundry project, pinned to Solidity 0.8.37, OpenZeppelin 5.7.0 and forge-std 1.16.2. Ryodan Keys v3 has four sequential phases: Pioneer/Operative reserve guaranteed allowlist allocations; Recruit is allowlist FCFS; Civilian is public FCFS. Default prices are 0.005/0.002/0.001/0.01 ETH and independent per-wallet caps are 4/6/6/10. Prices, caps and current/future lists are admin-configurable. All phases share 5,900 paid keys plus a separate 500-key treasury allocation.
- `mint(amount, expectedPhase, expectedUnitPrice)` checks the active phase and quoted price; token IDs are assigned sequentially. `phases`, `allowlisted`, `mintedInPhase`, `remainingAllowance` and `totalGtdReserved` expose allocation state. `advancePhase` permanently closes the previous phase, releases unused guarantees and pauses the next phase; `setMintPaused` resumes it. `mintPayment` preserves each token's original refund amount. Deadline administration, original-minter refunds with burn/optional recipients, and one-shot reveal after all 6,400 mints remain supported. Contracts have no upgrade or migration mechanism.
- The v3 API is exported in `ryodan-keys/abi/RyodanKeys.json`; `RyodanKeys.v2.json` preserves the legacy ABI. `ryodan-keys/scripts/export-abi.py --check` checks consistency with compiled artifacts. Deployment manifests under `ryodan-keys/deployments/` contain public Sepolia addresses and receipt evidence; `sepolia-v3.json` is management and `sepolia-v3-refund.json` is the expired four-phase refund QA sale.
- `console/` is a static Vite/ethers application with injected-wallet signing, pinned-block reads, role/network checks, transaction review and pending-transaction recovery. Its routes are `#mint`, `#sale`, `#treasury`, `#reveal`, `#access` and `#refund`. There is no backend API, database or server-side signer.
- The production console is https://ryodan.grooooog.space; its selected deployment is configured in `console/src/deployment.json`. Production uses Ethereum Sepolia; the local Anvil mode is development-only. The console selects the ABI by on-chain version, retains six v1/v2/v3 test deployments and rejects unsupported future versions. Reads use PublicNode with ethPandaOps fallback, bounded requests and explicit chain-ID validation. Branding tokens and official logo sources are documented in `DESIGN.md`.
- `.github/workflows/test.yml` runs Foundry tests with fuzzing/invariants, ABI validation, Slither and frontend unit/build/browser checks. `npm run test:deploy` exercises resumable management/refund scripts on isolated Anvil; `npm run test:browser` performs real UI transactions through a test wallet provider, including four-phase minting, mixed-price refunds, full sellout, reveal and withdrawal. `console/scripts/check-site.mjs` verifies the published read-only Sepolia UI and RPC recovery. V3 test/static-analysis evidence is under `ryodan-keys/docs/security/`.
- Integration, metadata/reveal, operator, security and deployment documentation is in `ryodan-keys/docs/`, starting with `FRONTEND_INTEGRATION.md` and `MANAGEMENT_CONSOLE.md`.
