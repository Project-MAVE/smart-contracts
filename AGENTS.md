## Project reference

- `ryodan-keys/` is the Foundry project, pinned to Solidity 0.8.37, OpenZeppelin 5.7.0 and forge-std 1.16.2. Ryodan Keys v7 (`CONTRACT_VERSION = 7`, see `ryodan-keys/docs/V7_CHANGES.md`) has four sequential phases: Pioneer/Operative reserve guaranteed allowlist allocations (each Pioneer once: 4 keys across both); Recruit is allowlist FCFS; Civilian is public FCFS. The constructor sets the approved prices 0.0075/0.012/0.0135/0.015 ETH per key and caps 4/4/10/20; `configurePhase` works only before Pioneer opens. Supply is **6,666 = 6,166 paid + 500 treasury** (`MAX_PUBLIC_SUPPLY`, `MAX_TREASURY_SUPPLY`), token IDs 1–6666. The admin role moves only in two steps (`AccessControlDefaultAdminRules`).
- `mint(amount, expectedPhase, expectedUnitPrice)` checks the active phase and quoted price; token IDs are assigned sequentially across paid and treasury mints. `phases`, `allowlisted`, `mintedInPhase`, `remainingAllowance` and `totalGtdReserved` expose allocation state. `advancePhase` permanently closes the previous phase, releases unused guarantees and pauses the next phase; `setMintPaused` resumes it. `treasuryMint` mints the 666 treasury keys in any phase. The deadline is immutable. Success needs all 6,666 mints; there is no reveal, keys read the SBT set while locked and the NFT set once unlocked (sellout or kept). After an unsuccessful deadline original minters keep or refund for 72 hours (`settle`), then anyone refunds; `refundBatch` defers failed payouts to `pendingRefund`. Contracts have no upgrade or migration mechanism.
- The v7 ABI is exported in `ryodan-keys/abi/RyodanKeys.json`, the only ABI the console uses; older ABIs were removed because the console manages only v7. `ryodan-keys/scripts/export-abi.py --check` checks consistency with compiled artifacts. Deployment manifests under `ryodan-keys/deployments/` contain public Sepolia addresses and receipt evidence: the v1–v4 files are historical; `sepolia-v6.json` is the current v6 test deployment.
- `console/` is a static Vite/ethers application with injected-wallet signing, pinned-block reads, role/network checks, transaction review and pending-transaction recovery. Its routes are `#mint`, `#sale`, `#treasury`, `#reveal` (read-only metadata), `#access` and `#refund`. There is no backend API, database or server-side signer.
- The production console is https://ryodan.grooooog.space; its selected deployment is configured in `console/src/deployment.json`: the v6 test deployment `0xd069E170ECD211ca09157Afe6E9110E322BC30f8` on Sepolia (2026-11-20, block 12176051, receipts in `ryodan-keys/deployments/sepolia-v6.json`). It is served from a persistent copy of the build on the Mac Pro (`~/Services/ryodan-console/dist`), not from the repository's `console/dist/`. Production uses Ethereum Sepolia; the local Anvil mode is development-only. The console manages only v6 and refuses any other `CONTRACT_VERSION`. Reads use PublicNode with ethPandaOps fallback, bounded requests and explicit chain-ID validation. Branding tokens and official logo sources are documented in `DESIGN.md`.
- `.github/workflows/test.yml` runs Foundry tests with fuzzing/invariants, ABI validation, Slither and frontend unit/build/browser checks. `npm run test:deploy` exercises resumable management/refund scripts on isolated Anvil; `npm run test:browser` performs real UI transactions through a test wallet provider, including four-phase minting, mixed-price refunds, the full 6,666-key sellout, the 72-hour keep-or-refund window, withdrawal and treasury burn. `console/scripts/check-site.mjs` verifies the published read-only Sepolia UI and RPC recovery. Historical v3/v4 test and static-analysis evidence is under `ryodan-keys/docs/security/`.
- Integration, metadata, operator, security and deployment documentation is in `ryodan-keys/docs/`, starting with `AGENT_HANDOFF_V6.md`, `FRONTEND_INTEGRATION.md` and `MANAGEMENT_CONSOLE.md`. `SEPOLIA_RUNBOOK.md` records the v6 Sepolia test deployment and the historical v1–v4 ones. `metadata-test/` is the generator of the random pixel-art test metadata used by the Sepolia v6 deployment (not the final artwork).
